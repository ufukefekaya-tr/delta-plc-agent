# Security reporting

Use the repository's **Security → Report a vulnerability** page for sensitive findings. Include the affected commit and a neutral reproduction. Keep credentials, plant details and customer files out of public issues.

Exact-target routing, external profiles, source/revision binding, operation ownership and uncertain-outcome reconciliation are engineering boundaries. [Canonical policy](SYSTEM_PROMPT.md) · [Runtime contracts](docs/UNIVERSAL_RUNTIME.md).

CI runs without hardware. Native and live operations use the current host's configured tools and authorized target. Old reports and fixtures never enroll a device.
