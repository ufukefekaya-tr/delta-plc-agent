## English announcement draft

Meet **Delta PLC Agent** — the agent-native PLC engineering toolkit.

One MCP connects exact-model routing, isolated workspaces, AX tools, ISPSoft transformations, DVP monitoring and traceable workflows. Six engineering roles, checkpoints and reusable lessons give agents a shared process.

Start with the offline IL → MPU → IL demo. Connect your MCP client, explore the catalog, or contribute an adapter.

Built by **ufukefekaya-tr**. MIT licensed. Engineers and agent builders welcome.

https://github.com/ufukefekaya-tr/delta-plc-agent
