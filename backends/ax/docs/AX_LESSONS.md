# Transfer ledger for every source kaizen candidate

Private source paths remain in the internal archive; [public provenance](../../../docs/public/PROVENANCE.md) describes the public distribution.
This ledger transfers applicable lessons, not machine code, values or authority.
The destination root owns the canonical policy; the backend adds no independent
approval rules. Historical claims do not certify this newly generalized build.

| Source record | Transferable lesson | Application and limit |
|---|---|---|
| KZ-20260820-001 | Separate scoped local commits from remote publication; one writer per file and isolated worktrees. | Root policy owns implementation. |
| KZ-20260820-002 | Reload committed bootstrap and exact task/checkpoint after resume. | An acknowledgement alone is not proof of understanding. |
| KZ-20260831-005 | Guard actual policy epoch, baseline and scope; stop on guard failure. | A checker not called provides no protection. |
| KZ-20260831-006 | Successful mutations close with a tested scoped local commit. | Does not grant push or history rewrite authority. |
| KZ-20260923-001 | Pin artifact, tools, profile and current target; measure API stages separately. Keep ongoing revision authority distinct from consumed deployment records. | Historical native/live acceptance is exact-revision evidence, never a portable live grant. |
| KZ-20260925-001 | Maintain artifact→export→build→runtime marker→target→acceptance lineage; distinguish package methods from task-local scripts. Stop cancellation ownership survives competing requests. | Preserved Stop-generation regressions; simulated tests do not certify physical stopping. |
| KZ-20261002-001 | Save/reopen and native source readback, narrow metadata comparison and explicit symbol publication; use the qualified dependency environment. | Native source existence is not public tag availability; offline model execution is not IEC execution. |
| KZ-20261005-001 | A scheduled task call can share a textual POU's name: select name and textual interfaces. Capture Stop generation before awaiting; distinguish OPC server state from application RUN. | Implemented in native project factory selector and regression. Gateway differences remain hypotheses until isolated. |
| KZ-20261005-002 | Observation deadlines, operation deadlines and transfer completion are different. Log/status errors during an uncertain transfer do not authorize process termination. | New creation supervisor only owns offline scratch creation; it is never used for download. Unicode exception reporting preserves the underlying error. |
| KZ-20261009-005 | Async draft editors must not have a second writer overwriting a newer edit. Validate a local snapshot, preserve draft/accepted/cache separation. | Multiple network writes are not made atomic by a counter or source-level test. |
| KZ-20261009-006 | Verify request, admission, owner and task boundaries individually; do not widen global mode permissions to fix a local command path. | A UI indication does not prove PLC command delivery or physical motion. |
| KZ-20261009-007 | Maintain Stop/recovery ordering while automating only required idle preparation. An IEC literal such as `16#...` must not be parsed as a host-language comment. | Restricted interpreters require grammar-specific regressions; immutable reviewed copies remain separate from user saves. |
| KZ-20261010-008 | Preserve current human Ladder topology; verify exact native address, type, bit offset and symbol access. | Source BOOL and vendor BIT metadata may differ legitimately. Tag export is not panel communication proof. |
| KZ-20261010-009 | Output deactivation does not prove held-command lifecycle is reset. Cross-test permit return with held commands. | Preserve raw Windows vendor command quoting and verified Unicode output; task-call names alone are not POU identity. |
| KZ-20261010-010 | Check bounds independently of short-circuit assumptions. Separate immutable artifact manifests from appendable shared metadata. A missing native operation gate must not be bypassed under another operation name. | Drive command acknowledgement is not physical movement; a test reference operation is not real homing qualification. |
| KZ-20261010-011 | Freshness recovery must not prevent reading the data needed to restore freshness. Compare command ownership and effects as well as public addresses. | Verify held-command and stale→status→source recovery. Validate target before pulse HIGH; bounded LOW/finally must precede extra queries. |
| KZ-20261010-012 | Draft→validation→accepted→consumer and retained revision transitions are distinct. Rebind worktree/epoch/scope before continuation. | Raw scalar edits are not atomic batches; an interrupted launch is not terminal success. |

Every candidate is accounted for above; machine-specific algorithms, parameters,
physical addresses, customer files, old grant records and accepted machine
artifacts are deliberately excluded. The preserved reusable code, regressions,
version-specific device identity and these lessons form the AX contribution.
